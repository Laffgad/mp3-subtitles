# Start here

Read [README.md](README.md) for PyCharm and terminal installation instructions.

1. Install Python 3.11 and the dependencies in a `.venv` environment.
2. Copy `.env.example` to `.env` and optionally add your own Hugging Face read token.
3. Put MP3 files in `audio`.
4. Run `main.py` without arguments.
5. Find subtitles in `results`.

Do not share your `.env`, recordings, or generated transcripts in public commits.
